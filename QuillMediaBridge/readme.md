# Quill Media Bridge

### Browse. Find. Select. Keep creating.

Connect AWT Media Library to Quill and put your existing images, videos, and albums within reach of the editor’s media picker.

## Your collection, organized for editing

**Media Library** gives you access to your complete collection and always appears first. Each album gets its own **Media Library - Album Name** provider, helping you focus on the assets for the page you are working on.

Use the search field to find media by filename. Browse images in a gallery with two columns, where each preview keeps its natural proportions. Load more results when you want to explore further.

## What you get

- A universal media provider, plus a dedicated provider for every album.
- Search within the complete library or the selected album.
- Image previews with flexible heights and no cropping.
- Support for image and video selection in compatible Quill fields.
- Selection through Quill’s existing media controls.
- Filename-based initial alternative text when choosing an image.

## Start using it

Install and enable the package together with Quill and Media Library. Open Quill’s media picker, choose a library, and select an asset to update the active field.

Album additions, renames, and removals are reflected the next time Quill requests the provider list.

## Fits into your AWT installation

This is a focused runtime integration: no separate dashboard, no additional routes, and no duplicate media storage. Browsing uses Media Library’s existing feed and access checks.

Requires **AWT Framework 27.0.0+**, **Quill 1.0.0+**, and **Media Library 1.0.0+**.
