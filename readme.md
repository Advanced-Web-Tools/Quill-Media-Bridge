# Quill Media Bridge

### Your media library, right inside Quill.

Bring your images, videos, and albums into the editing workflow. Quill Media Bridge connects AWT Media Library to Quill, so you can find and select existing media while building your pages.

## Find the right asset faster

Start with **Media Library** to browse your entire collection, or choose **Media Library - Album Name** to focus on a specific album. The complete library always appears first, with a dedicated provider for every album.

Search by filename, browse image previews, and load more results as you need them. A gallery in two columns displays images at their natural proportions, making portrait and landscape assets easy to recognize.

## Built for your editing workflow

- **One place for your media.** Reuse assets already stored in Media Library.
- **Album browsing.** Access organized collections directly from Quill’s media picker.
- **Search as you type.** Narrow down the current library or album without leaving the editor.
- **Images and videos.** Browse the media type supported by the field you are editing.
- **Visual image selection.** Preview images and see which source is currently selected.
- **More results on demand.** Explore larger collections with Load more.

Choose an asset to update the active Quill media field. Image selections also use the filename as the initial alternative text, ready for you to refine.

## Get started

Install and enable Quill Media Bridge alongside Quill and Media Library in your AWT installation. Open a media picker in Quill, choose the complete library or an album, and select your asset.

Existing albums become available when Quill loads the provider list. New and renamed albums appear the next time that list is requested.

## A focused integration

Quill Media Bridge works inside Quill’s existing picker. It adds no separate dashboard pages or routes and uses Media Library’s existing feed and access checks.
